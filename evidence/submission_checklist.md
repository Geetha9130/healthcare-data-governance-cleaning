# EdVyro Submission Checklist

## Required
- [x] One public/view-only project entry point can contain all supporting files.
- [x] Data dictionary
- [x] Cleaned dataset
- [x] Validation report
- [x] Exception log
- [x] Reproducible cleaning script
- [x] Privacy/de-identification explanation

## Before submitting
1. Replace the synthetic source with the official EdVyro CSV.
2. Run the cleaning script.
3. Open the cleaned CSV and verify it loads correctly.
4. Review the exception log.
5. Push the entire folder to a public GitHub repository.
6. Test the GitHub repository link in an incognito/signed-out browser.
7. Submit only the repository URL as the EdVyro proof link.
